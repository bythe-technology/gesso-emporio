# Gesso Empório

Site institucional da Gesso Empório, loja de materiais para construção a seco, pisos, acabamentos e iluminação em Registro/SP.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm test
npm run build
```

O formulário não armazena dados: ele prepara uma mensagem e abre o WhatsApp para confirmação do usuário.
